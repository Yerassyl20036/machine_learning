# ТЕХНИЧЕСКИЙ ОТЧЕТ 2

## 1. Наименование работы
Развитие baseline-подхода к сегментации сцен и 3D-реконструкции по данным глубины в рамках НИРМ.

## 2. Цель и задачи этапа
Цель этапа: выполнить и верифицировать часть запланированных на семестр работ, реализуемых с минимальными изменениями существующего кода.

Задачи этапа:
1. Реализовать аугментации обучающей выборки для задачи сегментации.
2. Реализовать взвешенную функцию потерь для учета дисбаланса классов.
3. Ввести план изменения шага обучения (scheduler) и обеспечить воспроизводимость эксперимента.
4. Подготовить воспроизводимый сценарий быстрого запуска и сравнительную таблицу результатов.

## 3. Исходные условия и ограничения
На момент выполнения этапа в проекте отсутствовали исходные файлы NYU Depth V2 и файл метаданных в каталоге data/processed/nyu_depth_v2.

В связи с этим для проверки корректности реализации и получения численных сравнений был выполнен пилотный эксперимент на синтетическом наборе данных NYU-like. Данный подход использован как технический стенд для подтверждения работоспособности изменений и подготовки к последующему запуску на полном реальном наборе данных.

## 4. Выполненные работы по плану

### 4.1 Реализация аугментаций
Файл: src/nyu_segmentation.py

Выполнено:
1. Добавлен флаг use-aug.
2. Добавлены аугментации train-выборки:
- горизонтальное отражение;
- мягкая цветовая вариативность;
- добавление гауссова шума.

### 4.2 Реализация weighted loss
Файл: src/nyu_segmentation.py

Выполнено:
1. Добавлен флаг weighted-loss.
2. Реализован расчет весов классов по обучающим маскам.
3. Подключен критерий CrossEntropyLoss с class weights.

### 4.3 Реализация scheduler и воспроизводимости
Файл: src/nyu_segmentation.py

Выполнено:
1. Добавлен флаг use-scheduler (StepLR).
2. Добавлен флаг seed для фиксирования случайности.
3. Расширена история обучения: дополнительно сохраняется значение learning rate.

### 4.4 Автоматизация прогона
Файл: tools/run_semester2_quick.py

Выполнено:
1. Подготовка синтетического NYU-like датасета.
2. Запуск baseline-конфигурации сегментации.
3. Запуск improved-конфигурации (аугментации + weighted loss + scheduler).
4. Запуск TSDF-реконструкции.
5. Формирование сводных файлов с метриками.
