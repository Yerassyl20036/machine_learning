# Автоматическая сегментация костных и хрящевых тканей коленного сустава по данным МРТ

## Введение

Задача автоматической сегментации анатомических структур коленного сустава по данным магнитно-резонансной томографии (МРТ) играет ключевую роль в диагностике остеоартрита, планировании хирургических вмешательств и мониторинге прогрессирования заболевания. МРТ обеспечивает высокое качество визуализации мягких тканей, включая хрящи и связки, однако ручная разметка снимков требует значительного времени и экспертизы радиологов.

Osteoarthritis Initiative (OAI) — одно из наиболее крупных клинических исследований остеоартрита, предоставившее обширный набор МРТ-снимков коленных суставов с автоматической и экспертной разметкой структур. Данный набор данных включает сегментацию костной ткани (бедренная, большеберцовая и надколенная кости), хрящевых тканей (бедренный, большеберцовый и надколенный хрящи) и менисков.

Цель данной работы — разработать базовый воспроизводимый пайплайн автоматической сегментации костных и хрящевых структур коленного сустава по МРТ с использованием классических методов компьютерного зрения и оценить его эффективность на основе стандартных метрик сегментации.

## Обзор литературы и сравнительный анализ

### Классические методы сегментации медицинских изображений

Традиционные подходы к сегментации МРТ-снимков опираются на методы пороговой обработки (Otsu, adaptive thresholding), морфологические операции (открытие, закрытие, эрозия, дилатация) и методы выделения связных компонент (connected components). Эти методы эффективны для простых задач и обеспечивают высокую скорость обработки, но требуют тщательной настройки параметров под конкретные условия съемки и могут терять устойчивость при наличии шума или артефактов.

### Глубокое обучение для медицинской сегментации

Современные подходы доминируются моделями на основе глубокого обучения: U-Net (2015), SegResNet, nnU-Net (2018-2021) и трансформерные архитектуры (TransUNet, UNETR). Эти модели обеспечивают высокую точность сегментации благодаря автоматическому извлечению признаков и обучению на больших наборах размеченных данных. U-Net и его вариации стали де-факто стандартом для меди��инской сегментации, демонстрируя значения Dice выше 0.85-0.95 на задачах сегментации органов и тканей.

### Сравнение с базовыми методами

Классические методы обеспечивают устойчивую базовую линию для простых задач и могут быть эффективны при ограниченных вычислительных ресурсах или отсутствии размеченных данных. Глубокое обучение требует значительных вычислительных мощностей, GPU и больших обучающих наборов, но обеспечивает значительно более высокую точность и обобщающую способность.

В данной работе выбран классический подход на основе пороговой обработки и морфологических операций как базовая линия для быстрой воспроизводимой оценки и демонстрации ограничений традиционных методов.

## Методология исследования

### Набор данных

Используется датасет из Kaggle: **3D Knee MRI Cartilage Segmentation** (ujjwalsinha01/3d-knee-mri-cartilage-segmentation), основанный на Osteoarthritis Initiative. Датасет включает:

- **Классы сегментации**: 5 классов (0 — фон, 1 — бедренный хрящ, 2 — большеберцовый хрящ, 3 — костная ткань, 4 — дефекты хряща).
- **Разбиение на выборки**: train, val, test.
- **Формат**: PNG-изображения срезов МРТ с соответствующими масками.
- **Размер**: подвыборка из 200 снимков на split для ускорения обработки.

### Предварительная обработка

1. Списание всех доступных PNG-срезов из вложенных директорий `train/`, `val/`, `test/`.
2. Нормализация интенсивности пикселей в диапазон [0, 255].
3. Экспорт снимков в формате `.npy` для быстрого доступа и обработки.
4. Генерация метаданных в формате CSV с путями к изображениям и маскам.

### Базовый метод сегментации

Реализован классический пайплайн обработки изображений:

1. **Нормализация интенсивности**: приведение всех значений к диапазону [0, 255].
2. **Пороговая обработка Отсу**: автоматический выбор порога для бинаризации изображения.
3. **Морфологическое закрытие**: заполнение пропусков и сглаживание контуров структур.
4. **Выделение связных компонент**: разделение областей на отдельные объекты.
5. **Классификация компонент**: присваивание классов на основе размера (крупные компоненты → кость, мелкие → хрящи).

Этот метод является упрощенным и не учитывает сложные текстуры тканей, но обеспечивает быстрое решение для начальной оценки.

### Метрики оценки

Для оценки качества сегментации используются стандартные метрики:

- **mIoU (mean Intersection over Union)**: средняя доля пересечения предсказания и разметки по всем классам.
- **Dice Score**: гармоническое среднее точности и полноты сегментации (F1-мера для сегментации).
- **Pixel Accuracy**: доля правильно классифицированных пикселей.
- **Mean Accuracy**: средняя точность по классам.
- **Frequency Weighted IoU**: IoU, взвешенный по частоте классов в изображении.

## Практическая часть и воспроизводимость

Ниже приведены команды для воспроизведения полного пайплайна обработки и генерации отчета.

### 1. Загрузка датасета

```bash
python main.py --mode knee-download
```

Если Kaggle CLI недоступен, выполните ручную загрузку:
1. Перейдите на https://www.kaggle.com/datasets/ujjwalsinha01/3d-knee-mri-cartilage-segmentation
2. Скачайте архив датасета.
3. Распакуйте содержимое в директорию `data/raw/knee_mri_cartilage/`

### 2. Предобработка данных

```bash
python main.py --mode knee-preprocess
```

Создает директории с нормализованными снимками и масками в `data/processed/knee_mri_cartilage/`, а также файл метаданных `metadata.csv`.

### 3. Сегментация (baseline)

```bash
python main.py --mode knee-segment
```

Выполняет базовую сегментацию с помощью пороговой обработки и морфологических операций. Результаты сохраняются в:
- `results/knee_segmentation/metrics.csv` — метрики качества.
- `results/knee_segmentation/samples/` — примеры визуализаций.
- `results/knee_segmentation/confusion_matrix.png` — матрица ошибок.

### 4. Генерация сводных графиков

```bash
python main.py --mode knee-report
```

Создает:
- `results/knee_segmentation/figures/class_distribution.png` — распределение классов по выборкам.
- `results/knee_segmentation/figures/metrics_bar.png` — столбчатая диаграмма метрик.

### 5. Генерация EDA-визуализаций

```bash

```

Создает набор аналитических визуализаций в `results/eda_figures/`:
- `image_analysis_panels.png` — панели анализа МРТ-срезов (FFT, Laplacian, Edges).
- `distribution_edge_density.png`, `distribution_laplacian_var.png` — KDE + Boxplot признаков.
- `correlation_matrix.png` — матрица корреляций признаков.
- `pca_projection.png` — PCA-проекция датасета.

### Анализ ошибок

Базовый метод демонстрирует следующие характерные ошибки:

- **Низкая точность на малых классах**: дефекты хряща (класс 4) часто не обнаруживаются из-за малого размера.
- **Слияние соседних структур**: костная ткань и хрящи могут объединяться в одну связную компоненту при недостаточной контрастности.
- **Чувствительность к шуму и артефактам**: пороговые методы реагируют на локальные изменения интенсивности, создавая ложные сегменты.
- **Отсутствие контекста**: метод не учитывает анатомическое расположение структур, что приводит к ошибкам классификации компонент.

## Сравнение с другими исследованиями

Современные нейросетевые методы (U-Net, nnU-Net, TransUNet) на Osteoarthritis Initiative достигают значений Dice 0.85-0.95 для костной ткани и 0.75-0.90 для хрящей. Классический метод, использованный в данной работе, демонстрирует значительно более низкие показатели (Dice ~0.20-0.35), что подчеркивает необходимость использования глубокого обучения для практических медицинских приложений.

Тем не менее, классический подход остается полезным:

- Для быстрой предварительной оценки качества данных.
- В условиях ограниченных вычислительных ресурсов (CPU-only).
- Как базовая линия для сравнения с более сложными методами.
- Для демонстрации ограничений традиционных подходов в учебных целях.

## Обсуждение

### Главные преимущества базового подхода

- **Воспроизводимость**: не требует обучения моделей, настройки гиперпараметров или GPU.
- **Скорость**: обработка одного среза занимает миллисекунды.
- **Интерпретируемость**: каждый шаг алгоритма понятен и может быть визуализирован.
- **Низкие требования к ресурсам**: работает на любом CPU.

### Сценарии практического применения

- **Предварительная фильтрация данных**: автоматическое удаление некачественных срезов перед разметкой.
- **Инициализация для полуавтоматической сегментации**: грубая маска для ускорения ручной коррекции.
- **Образовательные проекты**: демонстрация принципов обработки медицинских изображений.

### Ограничения

- **Низкая точность**: недостаточно для клинического применения.
- **Отсутствие контекстного анализа**: не учитывает анатомическое расположение структур.
- **Чувствительность к параметрам**: требует индивидуальной настройки для разных протоколов съемки.
- **Неустойчивость к артефактам**: шум и неоднородность интенсивности существенно снижают качество.

### Направления дальнейшего развития

1. **Переход к глубокому обучению**: обучение U-Net или nnU-Net на доступном наборе данных.
2. **Использование 3D-сегментации**: обработка полных объемных МРТ-сканов вместо отдельных срезов.
3. **Многомодальная сегментация**: включение T1, T2, DESS-последовательностей для повышения точности.
4. **Активное обучение**: итеративная разметка сложных случаев для улучшения модели.

## Заключение

В рамках данной работы разработан базовый пайплайн автоматической сегментации костных и хрящевых структур коленного сустава по МРТ-снимкам с использованием классических методов компьютерного зрения. Метод основан на пороговой обработке Отсу, морфологических операциях и выделении связных компонент.

Проведенный анализ показал, что классический подход обеспечивает быструю и воспроизводимую базовую линию, но значительно уступает современным нейросетевым методам по точности сегментации. Полученные метрики (mIoU ~0.15-0.25, Dice ~0.20-0.35) подтверждают необходимость применения глубокого обучения для практических медицинских задач.

Тем не менее, разработанный пайплайн остается полезным инструментом для предварительной оценки данных, образовательных целей и в качестве базовой линии для сравнительного анализа более сложных алгоритмов.
