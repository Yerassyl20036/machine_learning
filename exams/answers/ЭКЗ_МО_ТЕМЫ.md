# Машинное обучение — Обзор тем для чтения

> Дисциплина: Машинное обучение | 7М06101 | AIU | 2025-2026

---

## 1. Основы машинного обучения

**Что такое ML?** Раздел ИИ, в котором алгоритмы обучаются на данных без явного программирования правил. Три парадигмы: обучение с учителем (supervised), без учителя (unsupervised), с подкреплением (reinforcement learning).

**Жизненный цикл ML-проекта:**
Постановка задачи → Сбор данных → EDA → Предобработка → Feature Engineering → Обучение модели → Валидация → Деплой → Мониторинг

**Ключевые понятия:** признак (feature), целевая переменная, обучающая/валидационная/тестовая выборка, переобучение (overfitting), недообучение (underfitting), обобщение (generalization), bias-variance tradeoff.

---

## 2. Предобработка и работа с данными

**Типы данных:** числовые (непрерывные, дискретные), категориальные (номинальные, порядковые), текстовые, изображения, временные ряды.

**Работа с пропусками:** удаление, заполнение средним/медианой/модой, KNN-импутация, модельная импутация.

**Масштабирование:** StandardScaler (z-нормализация), MinMaxScaler, RobustScaler (устойчив к выбросам). Необходимо для: SVM, k-NN, линейных моделей, нейросетей. Деревья — не требуют.

**Кодирование категорий:** One-Hot Encoding (номинальные), Label/Ordinal Encoding (порядковые), Target Encoding, Frequency Encoding.

**Разбивка данных:** Train / Validation / Test. K-Fold Cross-Validation (K=5 или 10) — стандарт. Stratified — при дисбалансе классов. Временные ряды — только хронологически.

---

## 3. Линейные модели

**Линейная регрессия:** $\hat{y} = \mathbf{w}^T\mathbf{x} + b$. Обучение: МНК (аналитически) или градиентный спуск. Метрики: MSE, RMSE, MAE, R².

**Логистическая регрессия:** для классификации. Применяет сигмоиду: $P(y=1) = \sigma(\mathbf{w}^T\mathbf{x})$. Обучение: бинарная кросс-энтропия. Граница решений линейна.

**Регуляризация линейных моделей:** Ridge (L2) — все веса малые; Lasso (L1) — разреженные веса; Elastic Net — комбинация.

---

## 4. Деревья решений и ансамбли

**Дерево решений:** рекурсивное разбиение пространства признаков. Критерии: Gini impurity, Information Gain (entropy), MSE. Проблема: переобучение → pruning, ограничение глубины.

**Random Forest (Bagging):** много деревьев на бутстрэп-подвыборках + случайный выбор признаков при разбиении. Голосование/усреднение. Снижает дисперсию. OOB-оценка.

**Boosting:** последовательное обучение, каждая модель исправляет ошибки предыдущей. AdaBoost (веса объектов), Gradient Boosting (псевдо-остатки).

**XGBoost:** регуляризованный GB, второй порядок Тейлора, встроенная обработка пропусков, параллельность.

**LightGBM:** leaf-wise рост дерева, GOSS + EFB, очень быстрый на больших данных.

**CatBoost:** специализирован для категориальных признаков, ordered target encoding, симметричные деревья.

---

## 5. Метрические алгоритмы и SVM

**k-NN:** ленивый алгоритм, хранит все данные. Предсказание: K ближайших соседей. Метрики: евклидово, манхэттенское, Минковского. Малый K → переобучение, большой K → недообучение.

**SVM:** максимизирует зазор между классами. Опорные векторы. Soft-margin (параметр C). Ядровой трюк (RBF, polynomial) для нелинейных данных. Хорошо при высокой размерности, но медленный на больших данных.

---

## 6. Кластеризация

**K-means:** итерационно присваивает точки центроидам и пересчитывает центроиды. Минимизирует WCSS. K выбирается методом «локтя» или Silhouette. Инициализация k-means++.

**Иерархическая кластеризация:** агломеративная (снизу вверх). Linkage: single, complete, average, Ward. Дендрограмма — визуализация иерархии. Не нужно задавать K заранее.

**DBSCAN:** кластеры произвольной формы, обнаружение аномалий. Параметры: $\varepsilon$ (радиус), MinPts.

**Метрики качества кластеризации:** Silhouette score, Davies-Bouldin Index, Inertia.

---

## 7. Байесовский подход и Наивный Байес

**Теорема Байеса:** $P(\theta|D) \propto P(D|\theta) P(\theta)$. Posterior = Likelihood × Prior. MLE — максимизация правдоподобия. MAP — с учётом prior (эквивалентно регуляризации).

**Наивный Байес:** предполагает условную независимость признаков. Варианты: Gaussian NB (числовые), Multinomial NB (текст/частоты), Bernoulli NB. Быстр, хорошо для текстовой классификации.

---

## 8. Снижение размерности

**PCA:** линейное преобразование на оси максимальной дисперсии. Алгоритм: центрирование → SVD/eigendecomposition → выбор k компонент. Explained variance ratio — критерий выбора k. Применения: визуализация, шумоподавление, ускорение обучения.

**t-SNE / UMAP:** нелинейные методы для визуализации. t-SNE сохраняет локальную структуру. UMAP быстрее и сохраняет глобальную структуру.

**LDA (Linear Discriminant Analysis):** снижение размерности с учётом классов, максимизирует межклассовое/внутриклассовое расстояние.

---

## 9. Нейронные сети

**Нейрон:** $a = \phi(\sum w_i x_i + b)$. MLP — полносвязная сеть. Теорема: MLP с одним скрытым слоем — универсальный аппроксиматор.

**Функции активации:**
| Функция | Диапазон | Проблемы | Применение |
|---------|----------|----------|------------|
| Sigmoid | (0,1) | Затухание градиентов | Выход (бинарная) |
| Tanh | (-1,1) | Затухание градиентов | Скрытые (RNN) |
| ReLU | [0,∞) | Мёртвые нейроны | Скрытые (стандарт) |
| Leaky ReLU | (-∞,∞) | — | Скрытые |
| Softmax | (0,1), сумма=1 | — | Выход (многокласс) |

**Инициализация:** Xavier (sigmoid/tanh), He (ReLU). Нулевая — неправильно.

**Backpropagation:** правило цепочки для вычисления градиентов. SGD → Momentum → RMSprop → Adam.

**Регуляризация нейросетей:** L2, Dropout, Batch Normalization, Data Augmentation, Early Stopping.

---

## 10. Глубокое обучение

**CNN (Свёрточные сети):** для изображений. Свёртка → ReLU → Pooling → Flatten → Dense. Transfer Learning с предобученными моделями (ResNet, EfficientNet, VGG). Fine-tuning.

**RNN:** для последовательностей. Скрытое состояние передаётся по времени. Проблема: затухающие градиенты на длинных последовательностях.

**LSTM:** ячейка памяти + 3 гейта (input, forget, output). Учит долгосрочные зависимости.

**GRU:** упрощённый LSTM (2 гейта). Быстрее, меньше параметров, часто не хуже.

**Transformer:** механизм Self-Attention. Параллельная обработка. Основа BERT, GPT. Стандарт в NLP.

**Архитектуры:** ResNet (skip-connections), U-Net (сегментация), GANs (генерация), Autoencoder (сжатие), Diffusion Models.

---

## 11. Функции потерь и метрики

**Функции потерь:**

| Потеря | Задача | Особенности |
|--------|--------|-------------|
| MSE | Регрессия | Чувствительна к выбросам |
| MAE | Регрессия | Устойчива к выбросам |
| Huber | Регрессия | Компромисс MSE/MAE |
| Binary Cross-Entropy | Бин. классиф. | Логистическая регрессия |
| Categorical Cross-Entropy | Многокл. | + Softmax |
| Hinge Loss | SVM | Максимизирует margin |

**Метрики классификации:**
- **Accuracy** — не подходит при дисбалансе
- **Precision** = TP/(TP+FP) — точность среди предсказанных положит.
- **Recall** = TP/(TP+FN) — полнота, доля найденных из реально положит.
- **F1** = 2·P·R/(P+R) — баланс Precision/Recall
- **ROC-AUC** — качество ранжирования, независимо от порога

**Метрики регрессии:** MSE, RMSE, MAE, MAPE, R²

---

## 12. Feature Engineering и Feature Selection

**Feature Engineering:** создание признаков: полиномиальные, взаимодействия, агрегаты, признаки дат, логарифмирование. Часто важнее выбора алгоритма.

**Feature Selection:**
- Filter: корреляция, chi-squared, mutual information
- Wrapper: RFE (Recursive Feature Elimination)
- Embedded: Lasso (L1), feature importance деревьев, permutation importance

---

## 13. Оптимизация и гиперпараметры

**Оптимизаторы:** SGD, Momentum, AdaGrad, RMSprop, Adam (стандарт). Learning rate scheduling: step decay, cosine annealing, warmup.

**Подбор гиперпараметров:**
- Grid Search — полный перебор
- Random Search — случайный, обычно лучше
- Bayesian Optimization (Optuna, Hyperopt) — суррогатная модель + Acquisition Function
- HyperBand — ранняя остановка

**AutoML:** Auto-sklearn, TPOT, H2O, Google AutoML, AutoKeras — автоматизация всего pipeline.

---

## 14. Интерпретация моделей (XAI)

**Зачем?** Доверие, отладка, регуляторные требования (GDPR, EU AI Act), обнаружение bias.

**Глобальные методы:**
- Feature Importance (деревья)
- Partial Dependence Plots (PDP)
- Permutation Importance

**Локальные методы:**
- **LIME:** локально аппроксимирует модель линейной на возмущённых примерах. Model-agnostic, нестабилен.
- **SHAP:** теория игр (значения Шепли). Теоретически обоснован. TreeSHAP быстр для деревьев. Additive: $f(\mathbf{x}) = \phi_0 + \sum_j \phi_j$.

## 15. ML на больших данных

**Проблемы:** классические алгоритмы не масштабируются на TB данных.

**Инструменты:** Apache Spark + MLlib, Dask, Ray, Horovod (distributed DL).

**Парадигмы:**
- Data Parallelism: данные делятся, градиенты агрегируются (AllReduce)
- Model Parallelism: модель делится между GPU
- Parameter Server: централизованное хранение весов

**Онлайн-обучение:** mini-batch SGD, обновление на потоке данных без перебучивания всего датасета.

---

## 16. Современные направления и этика ML

**Современные направления:**
- **LLM** (Large Language Models): GPT-4, LLaMA, Gemini — миллиарды параметров
- **Foundation Models + Fine-tuning:** BERT, CLIP, SAM
- **Self-supervised learning:** без разметки
- **Diffusion Models:** Stable Diffusion, DALL-E
- **Federated Learning:** обучение без передачи данных на сервер
- **Multimodal AI:** текст + изображение + аудио
- **RAG (Retrieval-Augmented Generation):** LLM + поиск по базе знаний

**Этика и риски:**
- **Bias & Fairness:** модели наследуют предвзятость данных
- **Privacy:** обучение на личных данных, right to be forgotten
- **Adversarial attacks:** специальные входы обманывают модель
- **Distribution shift:** деградация модели при изменении данных
- **Data leakage:** утечка целевой переменной → ложный оптимизм
- **Углеродный след:** огромные вычислительные ресурсы для LLM
- **EU AI Act:** регуляторные требования к высокорисковым AI-системам
